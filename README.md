# 教师工作台（班主任版）

面向班主任的单机 Web 应用：**班级管理 · 学生管理 · 座位管理（自动/手动排座）· 文档管理 · 值日/学委管理**。数据全部保存在本机，无需联网、无需账号。

## 快速开始（Windows）

1. 双击 **`启动.bat`**
2. 首次运行会自动安装依赖并构建界面（约 1-3 分钟）
3. 浏览器自动打开 `http://localhost:3210`
4. 关闭启动窗口即停止服务

> 数据保存在 `data\` 文件夹（SQLite 数据库 + 上传文件）。**备份 = 复制整个 `data\` 文件夹**；应用内顶栏也有「备份数据」按钮（导出班级基础信息 JSON）。

## 功能一览

| 模块 | 功能 |
|---|---|
| 🏠 概览首页 | 今日值日自动计算、当前座位表缩略图、最近文档、快捷入口 |
| 📋 学生管理 | 增删改查、搜索筛选、批量导入/导出 Excel（提供标准模板）、详情抽屉 + 身高视力历史、回收站（软删除可恢复） |
| 💺 座位管理 | 座位网格、拖拽换座、右键锁定/设为空座、自动排座（身高>视力>男女/互助，近视坐中间，冲突提示）、平移轮换、历史布局回看/恢复、打印座位表 |
| 📁 文档管理 | 拖拽上传（图片/PDF/Office/文本 ≤200MB）、分类树+标签筛选、图片/PDF/文本内嵌预览、重命名、回收站 |
| 🧹 值日/学委 | 班干部选任（职务唯一）、值日分组、按周轮换值日表、打印 |
| 🏠 班级管理 | 多班支持、座位网格尺寸设置、删除确认 |

## 开发

```bash
npm install
npm run dev        # 开发模式：Vite(5173) + API 服务(3210)，自动打开浏览器
npm run build      # 构建前端到 web/dist
npm start          # 生产模式：Express 托管 web/dist + API
```

## 技术栈

- 后端：Node.js + Express + better-sqlite3（`server/`）
- 前端：Vue3 + Vite + Element Plus + exceljs（`web/`）
