# 教师工作台 v0.6.0 隐私模式与工作台上锁设计说明

## 目标

让教师可以把教师工作台安全切换为“班级公开模式”，供学生或班干部在班级电脑上使用；成绩、家校沟通、学生隐私档案、事件留痕等内容默认不可见，教师通过教师主密码切回教师工作台或临时解锁受保护模块。

## 范围

本版本聚焦本地单机应用的访问控制，不实现多端登录、云端同步、账号体系或远程协作。

包含：

- 首次设置、修改和验证教师密码。
- 教师模式与班级模式切换。
- 首次启动默认进入教师模式；教师开启班级公开模式后，应用重启继续保持班级公开模式。
- 支持一次性恢复密钥重置教师主密码。
- 模块级访问策略与临时解锁。
- 前端菜单/路由保护和后端 API 保护。
- 无操作自动回到班级模式。
- 访问控制设置的备份与恢复兼容。

## 术语

- `teacher`：教师模式，所有现有模块可用。
- `teacher`：教师模式，首次启动的默认模式。
- `classroom`：班级公开模式，只有白名单模块可用，隐私模块需要教师主密码进入教师工作台。
- `session`：当前应用进程中的教师会话，不把密码或密码摘要放到浏览器存储中；重启后不恢复。
- `module policy`：模块在班级模式中的策略，取值为 `open` 或 `protected`。

## 默认权限

班级模式默认开放：概览首页、座位管理、考勤管理、表现量化。

班级模式默认保护：数据分析、成绩管理、学生管理、文档管理、家校沟通、请假管理、班级设置、备份恢复。

值日管理、班委学委、课代表选择、使用指南和版本更新默认开放，但仍由统一路由门控；后续可在设置中调整的模块只限于非核心隐私模块。

## 交互流程

### 首次使用

首次使用时默认进入教师模式。教师第一次点击顶部“开启班级公开模式”时，设置 6 至 64 位教师主密码并确认；设置成功后生成一次性恢复密钥，只显示一次并提示保存。

### 进入班级模式

教师模式顶部显示“开启班级公开模式”按钮。点击后只要求确认，不重复输入密码；验证完成后清除当前教师会话、持久化 `classroom`，并跳转到概览首页。

### 返回教师模式

班级公开模式顶部只显示“教师入口”按钮。点击后打开密码对话框，验证成功后建立教师会话并切换为 `teacher`，跳转到概览首页。刷新页面、关闭并重新打开程序都不能绕过密码。

### 访问受保护模块

班级模式访问受保护路由时显示“此模块已保护”，提供“输入教师密码”按钮。验证成功后仅建立短时模块授权，默认有效 10 分钟；用户主动回到班级模式或自动回锁时立即失效。

## 安全边界

前端隐藏菜单不是安全边界。后端在每个受保护 API 请求上检查模式和模块授权；无授权返回 HTTP 403 和稳定错误码。密码验证接口只返回成功/失败，不返回密码摘要、盐或模式配置中的敏感字段。

密码使用 Node.js 内置 `crypto.scrypt` 生成摘要，随机盐单独保存；比较使用 `timingSafeEqual`。密码只存在请求内存中，前端不保存明文密码。恢复密钥使用高熵随机值，数据库只保存 SHA-256 摘要，并且每次成功重置后立即作废旧密钥并生成新的恢复密钥。

当前应用已有用于 WebView 与本地后端通信的 API token，它继续负责应用内部通信，不与教师密码混用。访问控制 session 使用后端进程内存中的随机 session token，通过 HttpOnly cookie 传递；浏览器开发模式也使用同一机制。

## 数据与迁移

新增 `app_settings` 键值表或等价设置存储，保存：

- 密码摘要、盐和算法版本。
- 当前公开/教师模式状态持久化；教师会话本身只保存在内存中。首次安装默认 `teacher`，教师主动开启后保存 `classroom`。
- 模块策略 JSON。

应用启动时读取持久化模式；没有模式配置的旧数据库按 `teacher` 启动。没有密码配置时可以继续使用教师模式，但开启班级公开模式前必须完成密码设置；不阻塞原有数据读取。

## 错误处理

- 未设置密码：模式切换和受保护模块访问返回可操作的引导错误。
- 密码错误：统一提示“密码不正确”，不区分用户不存在、未设置或摘要不匹配。
- 连续错误：同一后端进程按 IP/会话进行短暂退避，避免高频尝试影响本地使用。
- 过期授权：返回 403，前端清理本地模式状态并回到班级模式。
- 忘记密码：输入一次性恢复密钥和新密码，业务数据不删除，旧恢复密钥立即失效。
- 重启：所有内存教师会话失效；若持久化模式为班级公开模式，应用继续进入班级公开模式。

## 验收标准

1. 首次启动默认教师模式；教师未设置密码时不能开启班级公开模式，界面会引导完成设置。
2. 开启班级公开模式不重复输入密码；从班级公开模式进入教师工作台必须输入正确主密码。
3. 修改密码必须输入当前密码；恢复密钥只可使用一次。
4. 重启或刷新后不会恢复教师会话；已开启的班级公开模式继续生效。
4. 班级模式下受保护页面不能通过菜单、直接 URL 或 API 请求访问。
5. 临时解锁只授权指定模块，10 分钟后失效。
6. 既有 60 项基线测试继续通过，并新增访问控制单元、API 和 UI 契约测试。
