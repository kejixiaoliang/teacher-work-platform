# 教师工作台 v0.5.0 班主任日常工作台设计说明

> 设计日期：2026-08-21  
> 目标版本：v0.5.0  
> 基线版本：v0.4.2

## 本批范围

实现结构化跟进事项、学生详情跟进入口和首页今日工作台。学生成长报告与班级月报保留在 V0.5.0 后续批次，不在本批次引入。

## 设计决策

- 保留 `students.follow_up_status` 和 `follow_up_note` 作为学生级摘要。
- 新增 `follow_up_tasks` 表保存可追踪明细，状态为 `pending`、`in_progress`、`completed`、`cancelled`。
- 跟进事项关联 `class_id`、`student_id`，可选记录时间线来源；不把结构化数据继续塞入备注字符串。
- `/api/workbench/today?class_id=<id>` 是只读聚合接口，使用本地 `YYYY-MM-DD` 日期，不隐式修改考勤、请假或成绩。
- 首页聚合今日考勤、请假、值日、近期考试、待跟进和逾期事项；原有备份和预警能力继续保留。

## 验收边界

- 旧数据库升级到新版本时原有数据保持不变，新增表和索引可重复启动。
- 跟进事项支持新增、编辑、完成、取消、重新打开，并按班级、学生和状态查询。
- 首页事项可跳转到学生、考勤、请假、值日、成绩或学生跟进入口。
- 新增 API、迁移和备份兼容均有自动化测试；完整测试和生产构建通过。
