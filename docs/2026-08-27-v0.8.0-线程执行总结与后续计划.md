## 4. 编译问题处理记录

曾出现微信开发者工具错误：

```text
pages/attendance/index.wxml
unexpected `�`
```

原因是旧版本 WXML 中使用了中文属性表达式，例如 `item.出勤`。现已改为兼容字段：

- `item.present`
- `item.late`
- `item.leave`
- `item.absent`

另曾出现：

```text
pages/guide/index.js, file not found
```

当前 `guide` 页面文件实际存在且已纳入 Git，并已增加页面注册完整性测试。开发者工具遇到旧错误时，应确认打开的是当前 worktree，并清除缓存后重新编译。

## 8. 后续执行规则

1. 每次只推进一个可验证节点。
2. 修改前先检查客户端对应页面、字段和 API，不能凭空增加业务。
3. 小程序只改变布局和交互步骤，不删除客户端已有核心能力。
4. 所有写操作必须携带正确的 `datasetId`，涉及班级时必须携带 `classUuid`。
5. 不修改 V0.7.0 已发布数据格式的读取能力。
6. 新字段必须可选、可默认，并兼容旧数据。
7. 每个节点完成后运行专项测试并立即提交。
8. 未经明确确认，不部署 CloudBase 云函数或修改线上数据。
9. 不以“页面存在”“契约测试通过”代替真实功能完成。
10. 最终完成前必须进行微信开发者工具真实操作验收。
