# 教师工作台（班主任版）PRD

> 状态：设计定稿 ✅ ｜ 阶段一/二（基础功能）已实现 ✅ ｜ 阶段三（数据分析+成绩+考勤+成长档案+家校沟通）已实现 ✅
> 一句话：给班主任用的单机 Web 应用——管班级、管学生、排座位、管文档、管值日。

---

## 1. 项目概述

| 项 | 内容 |
|---|---|
| 目标用户 | 班主任（非程序员，电脑操作水平一般） |
| 使用形态 | 单机 Web 应用：双击 `启动.bat` → 自动打开浏览器访问 `localhost` |
| 部署 | 本机运行，无需联网、无需账号 |
| 数据存储 | 本地 SQLite（`data/teacher.db`）+ 本地文档文件夹（`data/files/`） |
| 备份 | 备份 = 复制整个 `data/` 文件夹；应用内提供一键备份/恢复 |
| 隐私 | 数据不出本机 |

## 2. 技术栈

- 后端：Node.js + Express + better-sqlite3
- 前端：Vue3 + Vite + Element Plus
- 文件上传：multer
- Excel 导入导出：前端 exceljs（导入标准模板 / 导出表格）
- 文档预览：图片/PDF/文本内嵌预览；Office 文件仅提供下载

## 3. 整体架构

```
teacher-work/
├─ server/            # Node + Express 后端
│  ├─ index.js        # 入口：启动服务 + 打开浏览器
│  ├─ db.js           # SQLite 初始化 + 建表 + 种子
│  └─ routes/         # classes / students / seats / documents / duties
├─ web/               # Vue3 前端
├─ data/
│  ├─ teacher.db      # SQLite
│  └─ files/          # 上传文档（按 班级/月份 分目录）
├─ docs/PRD.md
└─ 启动.bat           # 双击启动：装依赖(首次)→起服务→开浏览器
```

## 4. 数据模型（定稿）

### classes 班级表
`id, name(如2025级1班), academic_year(如2025-2026), term(上/下), seat_rows, seat_cols, head_teacher, remark, created_at, updated_at`

### students 学生表
| 分组 | 字段 |
|---|---|
| 基础 | `school_no`(全校唯一学号), `name`, `gender`, `birth_date`, `phone`, `parent_phone`, `is_boarding`, `interest_duty`(兴趣特长/担任职务), `health_note`(健康状况/过敏史), `remark` |
| 排座输入 | `height_cm`, `vision_left`, `vision_right`(算法取较差眼), `is_myopia`, `grade_level`(优/良/中/待提高), `seat_note`(特殊座位需求：必须前排/避免与XX相邻) |
| 状态 | `status`(在读/转出/休学——转出休学不排座但留档) |
| 软删除 | `deleted_at`(进回收站，可恢复) |

### student_metrics_history 学生指标历史表
`id, student_id, term(如2025-2026上), height_cm, vision_left, vision_right, grade_level, is_myopia, recorded_at`
- 「📸 学期存档」= 全班当前指标快照入历史
- 排座可选「当前值」或「某学期历史值」回填
- 学生详情页展示身高/视力随学期变化曲线

### seats 座位表
`id, class_id, student_id(可空=空座), row, col, locked(是否锁定), created_at`
- 布局保存时整表重写；历史布局存 `seat_layouts`

### seat_layouts 排座记录表
`id, class_id, created_at, rule_snapshot(JSON), seats_snapshot(JSON), remark`
- 可回看任意历史布局（第3周坐哪、第8周坐哪）

### documents 文档表
`id, class_id, original_name, stored_name, category(类型), size, mime, tag, uploaded_at, deleted_at`

### duties 值日/学委表
`id, class_id, student_id, role(值日生/学委/班长/课代表…), group_no(值日组号), week_days, term, remark`
- 「担任职务」档案字段为展示性；正式职责以此表为准

## 5. 功能模块（定稿）

### 概览首页（打开工作台默认进入）
- 今日值日组（根据当前周次自动计算）
- 当前座位表缩略图
- 最近上传文档
- 快捷入口（排座/上传/存档）

### 📋 学生管理
- 表格：学号/姓名/性别/身高/视力/成绩/状态
- 工具栏：搜索、筛选（性别/状态/近视/住宿）、新增、批量导入 Excel（提供标准模板）、导出 Excel、批量操作
- 行点击 → 右侧抽屉：完整档案 + 身高/视力历史曲线
- 新增/编辑弹窗：三个 Tab（基本信息 / 健康与排座 / 其他）

### 💺 座位管理
- 讲台标示居上；座位卡片显示姓名 + 身高/视力徽标；空座灰色「空」；锁定 🔒
- 手动模式：拖拽换座；右键菜单（锁定/解锁/设为空座）
- 自动模式：设置弹窗（勾选规则、数据来源）→ 生成 → 冲突提示列表 → 接受/重新生成
- 工具栏：手动/自动切换、保存布局、历史记录、↻平移轮换(N行M列)、导出打印座位表

### 📁 文档管理
- 左：分类树（类型/标签/月份）；右：缩略图网格
- 工具栏：拖拽上传、重命名、下载、删除（软删除）、标签管理、搜索
- 预览：图片/PDF/文本内嵌；Office 提示下载

### 🧹 值日/学委
- Tab1 班干部：角色清单（学委/班长/课代表）→ 关联学生
- Tab2 值日表：分组管理 → 轮换规则（组数、按周轮换）→ 一键生成「周次×星期→组」→ 导出打印

### 🏠 班级管理
- 班级信息编辑、座位网格尺寸（行×列）、班级维度备份/恢复

## 6. 排座算法（定稿）

优先级：**身高 > 视力 > 男女/互助**（用户确认）

```
第0步 硬约束：seat_note 特殊需求 → 锁定到指定/前排座位，不参与排序
第1步 主排序：身高升序 → 同身高按较差眼视力升序（视力差在前）
第2步 蛇形填充：奇数行左→右、偶数行右→左；近视优先坐中间列
第3步 软约束：同桌检查（默认同性同桌，可开「男女搭配」；
        「待提高」邻近「优/良」互助）——冲突时保身高/视力，冲突位打标
第4步 输出布局 + 冲突提示列表（供手动微调）
```

- 手动模式独立可用；自动排座尊重锁定座位
- 每次保存布局存 seat_layouts（规则快照+坐标快照）
- 轮换：一键全班平移 N 行 M 列

## 7. 体验规范（定稿）

| 项 | 决策 |
|---|---|
| 首页 | 有概览首页（今日值日/座位缩略图/最近文档） |
| Excel | 必须支持批量导入（标准模板）+ 导出 |
| 预览 | 图片/PDF/文本内嵌；Office 下载 |
| 删除 | 软删除 + 回收站（学生/文档），可恢复 |
| 顶栏 | 当前班级切换（单班时隐藏）、全局搜学生（姓名/学号）、学期存档、备份 |
| 容错 | 所有删除有确认；导入有结果报告（成功N条/失败M条及原因） |

## 8. 实现阶段划分（建议）

- **阶段一（核心闭环）**：数据层 + 班级管理 + 学生管理（含 Excel 导入导出）+ 座位管理（手动拖拽 + 自动排座 + 历史布局）→ 开学即可用
- **阶段二**：文档管理 + 值日/学委 + 概览首页
- **阶段三**：备份/恢复、学期存档历史曲线、回收站、打印优化、打包体验（启动.bat 完善）
