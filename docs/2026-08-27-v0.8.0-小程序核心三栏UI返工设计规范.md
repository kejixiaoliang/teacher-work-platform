# 教师工作台 v0.8.0 小程序核心三栏 UI 返工设计规范

> 建立日期：2026-08-27  
> 适用范围：首页、工作台、设置，以及后续所有小程序业务页  
> 返工原因：首版页面只有功能入口，没有形成可识别、可复用的界面设计系统。

## 一、设计目标

小程序面向班主任/教师本人使用。首页回答“今天班级状态怎样”，工作台回答“我要处理什么”，设置回答“数据、身份和软件信息在哪里管理”。

本次返工只改变移动端的布局、层级、色彩和交互呈现，不增加客户端之外的业务功能，不改变数据字段、稳定 ID、CloudBase 集合和既有路由。

## 二、视觉方向

采用“编辑式教育工作台”方向：保留客户端已有的暖橙识别，同时引入纸张底色、墨色标题、编辑式眉题和克制的辅助色，使页面具有班主任工作记录册的识别感，而不是默认模板式管理后台。

### 颜色令牌

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `paper` | `#F5F2EA` | 页面背景 |
| `ink` | `#202A32` | 主标题和正文 |
| `accent` | `#C65A32` | 主行动、栏目眉题、当前状态 |
| `sage` | `#74836E` | 身份和辅助状态 |
| `line` | `#DED8CC` | 分隔线和边界 |
| `danger` | `#B94A3A` | 错误和风险提示 |

### 字体令牌

- 标题：`Noto Serif SC`，设备缺失时回退至 `Songti SC`。
- 正文：`Noto Sans SC`，设备缺失时回退至 `PingFang SC`、`Microsoft YaHei`。
- 数字/编号：`DIN Alternate`，缺失时回退至 `Courier New`。

## 三、三栏结构

### 首页

- 顶部使用 `01 / TODAY` 和“教师本人”建立身份与栏目定位。
- 主标题之后必须有一句说明当前任务的引导文案。
- 班级采用横向可滚动的选择条，当前班级使用暖橙底色和偏移阴影突出。
- 学生名单使用纸张面板展示，右侧显示学号或数量信息。
- 数据集未选择、加载失败和暂无数据必须使用明确状态块。

### 工作台

- 顶部使用 `02 / WORKBENCH`。
- 功能仍按客户端原有范围分为“班级与学生”“日常记录”“成绩与资料”。
- 每组增加英文栏目识别、中文标题和组序号，形成可扫描的层级。
- 功能项保持原有名称，采用整行触控区域和右侧方向标记。
- 不使用没有业务含义的统计卡片、装饰性图标或虚构指标。

### 设置

- 顶部使用 `03 / SETTINGS`。
- 保持原有“数据”“账号与授权”“帮助”分区。
- 每个分区增加职责标题，帮助用户理解入口用途，而不是只看到一串菜单。
- 高风险操作的说明放在页面引导语中，具体确认仍由业务页面负责。

## 四、移动端交互规则

- 每个可操作行的最小高度不低于 `82rpx`。
- 按压状态使用纸色加深反馈，不依赖悬停状态。
- 页面底部保留三栏固定导航，内容区域预留底部安全空间。
- 业务页继续使用相同的纸张面板、暖橙行动色和墨色文字令牌。
- 加载、空数据、错误、成功、禁用和无权限状态必须可区分。

## 五、参考证据

参考 UIZZE 中与设置、教育场景和分步操作相关的界面，仅转化其信息层级和操作密度：

- [Canva 设置页](https://uizze.com/screens/345fc4149fafbd7766b1aeb03a36cb31)：借鉴分组设置和开关/入口的层级关系，不复制品牌视觉。
- [Duolingo 教育选择页](https://uizze.com/screens/4102a7711ec7dbe9a56e03bc6385e3af)：借鉴教育产品中主标题、解释文案和下一步操作的层级，不复制插画和文案。
- [LinkedIn 设置流程](https://uizze.com/screens/699c762800075c7f3291)：借鉴单项设置的清晰分组和触控行，不复制其业务模型。

## 六、验收标准

- 首页、工作台、设置不再出现裸标题、裸按钮和大片无意义空白。
- 三栏页面均能在首屏识别栏目职责和主要操作方向。
- 所有客户端功能名称和原有路由入口保持不变。
- 视觉令牌统一，禁止页面各自重新定义一套颜色和字体。
- 不使用紫色系渐变、通用英文后台字体或 emoji 作为图标。
- 真实微信开发者工具验收时，至少检查 iPhone 12/13 模拟器下的首屏、滚动、按压反馈和底部导航遮挡。
