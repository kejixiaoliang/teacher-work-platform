# 教师工作台 v0.8.0 第一组问题修复设计

> 设计日期：2026-08-29  
> 设计范围：座位表、文档上传、文档预览、文档下载  
> 关联审查：[2026-08-29-v0.8.0-第一组问题代码审查与根因分析](../../current/2026-08-29-v0.8.0-第一组问题代码审查与根因分析.md)

## 1. 目标与非目标

### 目标

- 小尺寸窗口下，座位表从第一列到最后一列都可访问。
- 座位网格在有足够空间时自动适配，在不足时保留可用横向滚动。
- 座位卡片保持可读的最小尺寸，并为后续显示比例控制预留边界。
- 文档上传明确显示处理中、成功和失败状态。
- 文件卡片的预览、下载操作各只触发一次。
- 图片、PDF、TXT、Markdown 和 CSV 等简单格式提供应用内预览。
- 不支持应用内预览的格式明确显示文件路径和打开提示。
- 预览、下载和路径读取失败时提供可理解的反馈。

### 非目标

- 不新增作业管理或班主任日常台账模块。
- 不修改学生数据结构、Excel 字段配置或考试科目数据模型。
- 不强求 Word、Excel、PPT、压缩包和媒体文件在应用内渲染。
- 不把长期 API Token 放入文件 URL。

## 2. 座位表设计

### 2.1 布局边界

当前座位网格由行数、列数和走道模式决定。右侧画布必须成为唯一的横向滚动容器，网格本身从左侧起始位置布局，避免超宽内容居中后产生负向溢出。

约束如下：

- `.ws-body` 和 `.ws-canvas` 允许在 Flex 布局中收缩，避免把溢出推给应用根容器。
- `.ws-canvas` 设置 `min-width: 0`、`overflow-x: auto` 和左对齐。
- `.seat-grid` 使用 `width: max-content` 保留完整网格宽度，同时设置 `min-width: 100%` 让大屏下自然铺满。
- 座位宽度根据画布容器宽度和列数计算，限制在可读的最小值与最大值之间。
- 走道额外间距计入宽度计算；达到最小座位宽度后允许滚动。

### 2.2 显示策略

优先级从高到低为：

1. 完整可见时使用可用空间展示。
2. 不完整可见时保持最小可读尺寸，并显示横向滚动。
3. 滚动必须从第 1 列开始，能到达最后 1 列。
4. 保持现有拖拽换座、选择、锁定、平移、历史布局和打印行为。

本批不引入基于 `transform: scale()` 的视觉缩放，因为它会改变指针命中区域和滚动计算。若后续仍需要用户手动缩放，单独设计可访问性和交互规则。

## 3. 文档上传设计

### 3.1 状态模型

上传队列中的每个项目保持以下状态：

- `null`：请求尚未结束，界面显示“上传中”。
- `true`：服务端已完成文件落盘和数据库写入，界面显示“成功”。
- `false`：请求失败，界面显示服务端或网络错误并允许重新选择文件。

上传完成后等待列表刷新，再显示整体完成提示；弹窗关闭操作在仍有任务时需要二次确认或保持禁用，避免用户误以为任务已结束。

### 3.2 超时与错误

- 上传请求保留 15 秒超时，超时显示“上传超时，请重试”。
- 服务端已有扩展名、文件签名、容量、班级和孤儿文件清理校验，继续沿用。
- 大文件或慢请求不显示百分比时，也必须显示当前文件名和明确的处理中状态。

## 4. 文档预览与下载设计

### 4.1 支持范围

应用内预览：

- 图片：JPG、JPEG、PNG、GIF、BMP、WebP。
- PDF。
- 纯文本：TXT、Markdown、CSV。

不强求应用内预览：

- Word、Excel、PPT。
- ZIP、RAR、7Z。
- MP3、MP4、WAV、MOV。

### 4.2 单次操作

文件卡片继续支持点击预览，但内部“预览”和“下载”按钮必须阻止冒泡。用户点击下载时只执行下载；点击预览时只执行预览。

### 4.3 预览状态

预览弹窗打开后显示独立的加载状态。文件 Blob 成功读取后再显示内容；失败时显示错误状态和重试入口，不保留空白弹窗。

### 4.4 不支持格式

不支持的文件类型不再静默调用下载。前端先请求受保护的文件位置信息，向用户展示：

- 原始文件名。
- 当前实际存储路径。
- “请到该路径下使用本机软件打开”的提示。
- 复制路径操作。
- 另存为操作。

文件路径接口只返回当前已授权班级中的文件，并继续由本地 API Token 和文档访问控制保护。浏览器版不能直接打开本机目录，只显示路径和复制/另存为操作；桌面版后续可再增加“打开所在文件夹”。

### 4.5 文件访问安全

- 继续使用短时、单次、绑定文档的文件访问 Token。
- 不在文件 URL 中放置长期 API Token。
- 路径接口只返回服务端解析后的现有文件路径，不接受客户端传入路径。

## 5. 验收标准

- 在 1280px、1024px、900px 以下窗口中，座位表第 1 列和最后 1 列均可见或可滚动到达。
- 8 列双走道布局不会产生无法返回的左侧负向溢出。
- 座位移动相关现有测试全部通过。
- 多文件上传逐项显示最终状态，失败项显示原因。
- 预览按钮和下载按钮各只发起一个文件请求。
- 图片、PDF、TXT/Markdown/CSV 预览在加载中、成功和失败时都有明确状态。
- Word、Excel、PPT、压缩包和媒体文件显示实际路径，而不是弹出空预览窗。
- 文档授权、备份和核心工作流回归测试全部通过。
