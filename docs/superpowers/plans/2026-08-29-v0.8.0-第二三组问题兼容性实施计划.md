# 教师工作台 v0.8.0 第二、三组问题兼容性实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不破坏升级、备份恢复和历史数据的前提下，完善显示词条、考试科目、按星期值日和学生字段/Excel 配置。

**Architecture:** 自定义内容全部使用稳定键和独立配置数据，不把用户字段写成动态 SQLite 列，也不改动现有核心业务列名。新增配置表纳入 v0.8.0 的备份能力版本；旧备份在新版本中按默认配置兼容读取，新版本备份给旧版本时在预检阶段明确拒绝。Excel 通过隐藏元数据工作表携带稳定字段键，显示表头只作为可读标签。

**Tech Stack:** Vue 3、Element Plus、Express、SQLite、ExcelJS、Node.js 内置测试运行器、现有 JSON/ZIP 备份格式。

**Spec:** `docs/superpowers/specs/2026-08-29-v0.8.0-第二三组问题数据兼容性设计.md`

## Global Constraints

- v0.8.0 采用“预设字段目录 + 显示配置”，不开放目录外任意字段创建；不得修改核心字段的数据库列名和内部接口字段名。
- 预设字段使用不可变 `field_key`/稳定记录 UUID；改名、排序、隐藏不能改变键，删除只能归档。
- “隐藏住宿”只影响列表、筛选、表单、模板和导出显示，不删除 `students.is_boarding` 历史值。
- `app_settings` 含密码哈希、恢复密钥和访问策略，不得直接导出；只导出新增的非敏感配置表。
- v0.7.0 `formatVersion: 1` 备份必须能在 v0.8.0 恢复；未知更高版本必须在事务前拒绝且不能覆盖当前库。
- 已有成绩的科目名称不得被静默重写；v0.8.0 只允许新增或归档，改名必须提示历史成绩影响。
- Excel 导入第一阶段只保证软件生成模板和旧标准模板；第三方任意表格先展示未映射列，不自动猜测写入。
- 不新增学生作业管理或班主任台账模块。

## Test helper conventions

新增 HTTP 测试沿用现有 `tests/file-access.test.js` 的临时数据目录和 `startServer({ port: 0, apiToken, openBrowser: false })` 方式。各测试文件在顶部定义以下本地辅助函数，避免依赖真实用户数据：

```js
async function request(running, token, method, url, body) {
  const response = await fetch(`${running.baseUrl}${url}`, {
    method,
    headers: { 'content-type': 'application/json', 'x-teacher-work-token': token },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  return { status: response.status, body: await response.json().catch(() => null) };
}
```

`createClass`、`createExam`、`saveScore` 均通过该 `request` 辅助函数创建当前测试所需的最小记录；`openFreshDatabase` 使用 `fs.mkdtempSync(path.join(os.tmpdir(), 'teacher-customization-'))` 设置 `TEACHER_WORK_DATA_DIR` 后动态导入数据库模块。测试不得读取或修改工作区真实 `data/` 目录。

  id INTEGER PRIMARY KEY AUTOINCREMENT,
  class_id INTEGER NOT NULL REFERENCES classes(id) ON DELETE CASCADE,

  label TEXT NOT NULL,

  field_id INTEGER NOT NULL REFERENCES student_field_definitions(id) ON DELETE CASCADE,
