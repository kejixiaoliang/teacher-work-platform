# 教师工作台 v0.9.0 Windows 安装版与自动更新实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将教师工作台从当前仅有绿色便携版的 v0.8.0 升级为 v0.9.0，新增 Windows x64 每用户安装版、独立用户数据目录和可验证的 Tauri 自动更新链路，同时保留现有便携版。

**Architecture:** Web、Express、SQLite 和业务规则继续共用一套代码。Tauri 桌面层新增运行配置 profile：安装版把程序安装在用户程序目录、把数据放在 `%LOCALAPPDATA%\TeacherWork`，便携版继续把数据放在 EXE 同级 `data`；updater 只负责签名程序包的检查、下载和安装，数据库快照、迁移、回滚提示仍由应用负责。安装版和便携版使用独立构建配置，避免开启 NSIS bundle 破坏现有便携包链路。

**Tech Stack:** Tauri v2、Rust、Vue 3、Vite、Node.js/Express、SQLite、NSIS、Tauri updater plugin、Windows x64。

**Spec:** `docs/current/2026-08-29-v0.7.0-Windows安装版发行与自动更新-设计说明.md`

## Global Constraints

- 产品版本、Tauri 版本、Cargo 版本、更新记录和发布资产名称必须统一为 `0.9.0`。
- 安装版采用当前 Windows 用户安装，不默认申请管理员权限；卸载程序不得删除 `%LOCALAPPDATA%\TeacherWork\data`、备份和日志。
- 便携版继续使用 EXE 同级 `data`、`backups` 和 `logs`，继续支持现有手动升级方式。
- 业务代码只能消费已经解析并校验过的 `dataDir`，不得在页面或路由中自行判断安装版/便携版。
- updater 私钥、Windows 代码签名证书和生产凭据不得进入 Git；客户端只内置公开验签公钥。
- `latest.json` 必须最后发布；在真实发布前，更新端点使用本地 fixture 或测试端点验证，不把示例域名写入正式构建。
- 每个行为改动先补回归测试，再实现；每个阶段完成后运行针对性测试和 `npm test`。
- v0.9.0 首阶段保留单一 `stable` 通道；便携版暂不接入自动更新，除非另行确认扩大范围。
- v0.9.0 的安装、更新和便携包验收都必须满足关闭生命周期门禁：主程序退出后不得残留内置 Node sidecar。

- [x] 在 `src-tauri/src/lib.rs` 将窗口关闭、Tauri 退出事件和 sidecar 回收收口为幂等生命周期。
- [x] 增加 Rust 单元测试，验证 sidecar 被终止、等待并消费。
- [ ] 重建独立 Windows 便携包，执行正常关闭和 Node 残留 QA；QA 通过后才能关闭本问题。

## 需要用户确认或提供的事项

以下事项不阻塞本地架构和测试工作，但会阻塞正式自动更新发布：

1. 安装版是否确认采用“当前用户安装 + `%LOCALAPPDATA%\Programs\TeacherWork` 程序目录 + `%LOCALAPPDATA%\TeacherWork` 数据目录”。本计划按该方案推进。
2. 正式更新端点的稳定 HTTPS 地址，例如 `https://updates.<你的域名>/stable/latest.json`。在地址确定前，代码只保留可注入配置，不写示例域名。
3. 更新包和 `latest.json` 的托管方式：自有静态托管、CloudBase/COS/CDN，或先使用 GitHub Release。首版只要求客户端端点稳定可访问，不要求业务数据上云。
4. 是否已有 Tauri updater 签名密钥；如果没有，需要在本机或 CI 安全环境生成一套，私钥只保存在密码管理器/CI secret 中。
5. 是否有 Windows 代码签名证书。它不是本地 updater 验签的前置条件，但正式分发时建议配置；没有证书也可以先完成未签名内部测试包。
6. 旧便携版迁移首版采用“完整 ZIP 备份恢复”还是同时提供“选择旧便携目录迁移”。本计划首版只承诺完整备份恢复，避免未经用户确认扫描或搬移数据。
