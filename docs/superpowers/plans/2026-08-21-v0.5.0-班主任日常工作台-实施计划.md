# v0.5.0 班主任日常工作台实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 v0.4.2 基础上实现结构化跟进事项、学生详情跟进入口和首页今日工作台。

**Architecture:** 新增独立的 `follow_up_tasks` SQLite 表和 REST 路由，保留旧学生跟进摘要字段；新增只读 workbench 聚合接口，复用现有模块查询；Vue 侧在学生详情和概览首页增加闭环入口。

**Tech Stack:** Node.js、Express、better-sqlite3、Vue 3、Element Plus、Node test runner、Vite。

**Spec:** `docs/2026-08-21-v0.5.0-班主任日常工作台-设计说明.md`

## Global Constraints

- 实现阶段不在 `master` 直接开发；功能已在隔离分支完成，并合并到 `master` 的 v0.5.0 发布提交。
- 不删除或改变现有学生级跟进摘要字段。
- 日期接口使用本地 `YYYY-MM-DD`。
- 数据库迁移必须创建升级前恢复快照，并更新备份表清单。
- 生产代码必须先有失败测试，再写最小实现。

## 已执行任务

1. 数据库 v5 迁移和 `follow_up_tasks` 表、索引。
2. 跟进事项 REST API、状态流转和班级归属校验。
3. 全量备份和班级备份加入跟进事项。
4. `/api/workbench/today` 聚合今日考勤、请假、值日、近期考试和跟进事项。
5. 学生详情跟进事项新增、编辑、完成、取消和重新打开。
6. 概览首页今日工作台卡片和直接跳转入口。
