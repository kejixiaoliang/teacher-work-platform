# Windows 安装更新文件占用与残留进程修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (\`- [ ]\`) syntax for tracking.

**Goal:** 彻底消除教师工作台 Windows 安装版在覆盖安装和自动更新时因 node.exe、better_sqlite3.node 被占用而出现安装错误的问题。

**Architecture:** 在安装器、应用实例和后台进程三个边界分别建立保护。NSIS 在复制文件前关闭教师工作台进程树，并通过精确路径清理属于当前安装目录的 Node 进程；应用启动前使用 Windows 命名互斥体阻止重复实例；后台服务使用 Windows Job Object 管理，使主程序异常退出时系统自动回收后台进程。更新页面继续先备份数据，再停止当前后台服务，最后交给 Tauri updater 执行安装。

**Tech Stack:** Tauri 2、Rust、Windows API（windows-sys）、NSIS installer hooks、Vue 3、Node.js test runner。

**Spec:** docs/current/2026-08-30-v0.9.0安装版闪退问题排查与修复总结.md

**Execution status (2026-08-31):** Tasks 1–5 completed in order. Node tests 134/134 and Rust tests 5/5 pass; the new signed 0.9.0 acceptance installer is at `E:\工作台测试\教师工作台_0.9.0_进程保护最终验收-setup.exe`. ## Global Constraints

- 只修改安装版生命周期；便携版保留现有“程序目录旁 data”行为。
- 不得结束其他软件的 node.exe；清理必须精确匹配当前安装目录的 resources\\runtime\\node.exe。
- 安装版数据继续保存在 %LOCALAPPDATA%\\TeacherWork\\data，不得删除用户数据。
- 更新前必须先创建包含附件的 pre-update-* 恢复点。
- 更新器 endpoint 继续使用 HTTPS；生产私钥不得进入仓库、日志或安装包。
- 每个修复阶段都必须先有失败测试，再实现、验证和独立提交。
- CloudBase 只使用 test 目录，不指向 stable/latest.json。

### Task 2: Add the NSIS pre-install cleanup boundary

**Files:**
- Create: src-tauri/windows/hooks.nsh
- Modify: src-tauri/tauri.installed.conf.json:8-12
- Modify: tests/installer-config.test.js
- Test: tests/installer-process-safety.test.js

**Interfaces:**
- Consumes: NSIS NSIS_HOOK_PREINSTALL and the current install directory in $INSTDIR.
- Produces: a pre-install hook that closes teacher-work.exe and cleans only orphaned bundled Node processes.

- [ ] **Step 1: Implement the hook**

Create src-tauri/windows/hooks.nsh:

~~~nsh
!macro NSIS_HOOK_PREINSTALL
  ; Close every Teacher Work instance and its child tree.
  nsExec::ExecToLog 'taskkill.exe /F /T /IM teacher-work.exe'

  ; Kill only node.exe launched from this installation directory.
  nsExec::ExecToLog '$SYSDIR\\WindowsPowerShell\\v1.0\\powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "$root = [IO.Path]::GetFullPath(''$INSTDIR''); $node = [IO.Path]::GetFullPath((Join-Path $root ''resources\\runtime\\node.exe'')); Get-CimInstance Win32_Process -Filter \\"Name = ''node.exe''\\" | Where-Object { $_.ExecutablePath -and ([IO.Path]::GetFullPath($_.ExecutablePath) -ieq $node) } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"'
!macroend
~~~

The hook must never use taskkill.exe /IM node.exe, because that would terminate unrelated Node programs.

- [ ] **Step 2: Point the installed profile at the hook**

Add under bundle.windows.nsis:

~~~json
"installerHooks": "./windows/hooks.nsh"
~~~
