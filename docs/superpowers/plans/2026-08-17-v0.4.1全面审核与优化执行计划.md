# v0.4.1 全面审核与优化执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v0.4.0 稳定基线上完成前端、后端、数据库和 Windows 便携发布链路的全面审核，修复确认的高优先级问题，并形成可发布的 v0.4.1 候选版本。

**Architecture:** 保持 Vue 3 + Express + SQLite + Tauri v2 的本地优先架构，不在本轮引入账号、云同步或大型新模块。审核先以只读检查和自动化验证建立证据，再按 P0/P1/P2 优先级实施最小修复；每个修复必须有对应测试或可重复的验证记录。

**Tech Stack:** Vue 3、Vite 6、Element Plus、ECharts、Node.js、Express、better-sqlite3、ExcelJS、Tauri v2、SQLite、Node Test Runner、PowerShell。

## Global Constraints

- 产品版本基线为 `0.4.0`，本分支目标为兼容性修复版 `0.4.1`。
- 所有改动只发生在 `codex/v0.4.1-comprehensive-audit` worktree，不修改 `master`。
- 不新增账号系统、云端同步或与审核无关的新业务模块。
- 数据库迁移必须可回滚，升级前必须保留恢复快照。
- 浏览器与 Tauri WebView 继续共用同一套业务代码和 API。
- 不降低现有测试、构建、版本契约和便携包 QA 门禁。
