# 教师工作台 v0.8.0 第一组问题修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复座位表小屏不可达、文档操作重复触发和文件反馈不清晰问题，同时保持现有安全访问边界。

**Architecture:** 先在座位页面收敛 Flex/滚动边界和网格宽度计算；再在文档页面拆分单次事件、加载状态和不支持格式提示；最后在文档路由增加只读文件位置接口。所有改动通过现有 API、Tauri 保存文件桥接和短时文件授权复用，不引入新业务模块或第三方预览引擎。

**Tech Stack:** Vue 3、Element Plus、原生 CSS、Express、SQLite、Node.js 内置测试运行器、Tauri v2。

**Spec:** `docs/superpowers/specs/2026-08-29-v0.8.0-第一组问题修复设计.md`

## Global Constraints

- v0.8.0 只修复和完善现有模块，不新增作业管理或班主任日常台账。
- 不在文件 URL 中放置长期 API Token；继续使用短时、单次、绑定文档的访问 Token。
- 不引入 Office/压缩包在线预览引擎；不支持格式显示路径并提供另存为。
- 座位网格达到最小可读尺寸后允许横向滚动，但第 1 列必须可访问。
- 每个任务先写失败测试，再写最小实现，再运行专项测试。

### Task 3: 不支持预览的文件显示受保护的实际路径

**Files:**
- Modify: `server/routes/documents.js:216-260`
- Modify: `web/src/api.js:113-145`

**Interfaces:**
- Consumes: 文档 ID、当前班级访问控制和 `filesDir`。
- Produces: `GET /api/documents/:id/location` 返回 `{ id, originalName, path, exists }`；前端使用该结果展示路径，不接受客户端路径输入。

- [ ] **Step 1: Write the failing test**

在 `tests/file-access.test.js` 增加一个已上传文档的位置查询用例，断言响应返回同一文档 ID、原始文件名、绝对路径和 `exists: true`；断言不存在的文档返回 404。同步在 UI 测试中断言不支持格式进入位置提示流程。

- [ ] **Step 2: Run test to verify it fails**

Run: `node --test tests/file-access.test.js tests/documents-ui.test.js`

Expected: FAIL because `/location` 接口不存在，前端没有位置提示流程。

- [ ] **Step 3: Write minimal implementation**

在 `server/routes/documents.js` 中，在 `/:id/file-token` 之前增加 `GET /:id/location`：

1. 校验正整数文档 ID。
2. 查询未删除文档并解析 `path.join(filesDir, row.stored_name)`。
3. 仅返回服务端生成的路径、原始文件名和物理文件是否存在。
4. 文档不存在或已删除时返回现有文档错误。

在 `web/src/api.js` 增加 `documents.location(id)`。

在 `Documents.vue` 中：

1. 增加“不支持预览”说明弹窗。
2. `preview()` 对图片/PDF/文本以外的类型调用位置接口，不再静默下载。
3. 展示路径和复制路径按钮；复制失败时显示明确提示，用户可按路径到本地打开文件。
4. 浏览器版只提供路径、复制和另存为，不调用无法获得的本机目录能力。

Run: `node --test tests/file-access.test.js tests/documents-ui.test.js tests/workflow-smoke.test.js`
