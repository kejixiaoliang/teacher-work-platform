# 学生表现量化模块全面优化规划

## 1. 目标

在保持 0.4.0 既有业务规则的前提下，全面修复学生表现量化模块的历史数据、统计口径、规则生命周期、导出一致性、响应式布局和测试覆盖问题。

核心原则：

- 历史记分和修正历史可长期追溯，不因学生或班级管理动作被静默删除。
- 规则修改只影响未来新增记录，统计和导出必须使用明确且一致的筛选条件。
- 停用规则必须同时受到前端和后端约束。
- 窄屏和宽屏都不能出现页面级横向溢出；操作列按钮必须随列宽合理伸展。
- 先补充可复现的回归测试，再修改实现，最后执行完整测试与构建验证。

## 2. 已确认问题

### P0：数据安全

1. `assessment_records.class_id` 和 `student_id` 使用级联删除；删除班级或彻底删除学生会连带删除记分和修正历史，与“过往数据不主动删除”冲突。
2. 记录历史快照虽已保存，但修正历史的字段清单和前端展示没有完整呈现项目名称、分类名称和分值变化。

### P1：业务一致性

1. 顶部“本月”概览依赖流水筛选数据，筛选其他月份后会显示错误口径。
2. 统计页导出使用流水页记录，不一定匹配当前月度/学期筛选。
3. 后端只检查行为项目启用状态，未阻止停用分类下的项目被 API 直接记分。
4. 月份只做格式校验，`00` 和 `13` 等非法月份可能通过；每日统计结束日期存在字符串拼接边界问题。
5. 分类贡献图使用净分绝对值，无法区分加分和扣分，净分为 0 的分类被隐藏。

### P2：性能与体验

1. 批量记分逐学生执行重复查询，形成 N+1 查询。
2. 流水一次性加载全部记录，没有分页或上限策略。
3. 批量记分跳过明细只通过提示展示数量，没有结构化查看入口。
4. 修正历史默认旧记录在前，查看最新修正不够直观。
5. 规则管理尚未提供分类和行为项目排序操作。
6. 当前测试没有真实浏览器响应式回归，无法自动防止页面级横向溢出复发。

## 3. 实施范围

### 阶段一：数据安全与历史追溯

- 调整量化记录的删除策略，禁止班级/学生物理删除时级联删除量化历史；必要时保留记录并将关联对象置为历史快照状态。
- 增加历史数据保护回归测试：删除学生、删除班级、备份恢复后，量化记录和修正历史仍可查询和导出。
- 扩展修正快照字段清单，明确展示学生、分类、行为项目、分值、日期、备注的前后变化。
- 历史展示优先使用 revision 中的快照，不实时反查当前规则名称。

### 阶段二：业务校验与统计口径

- 新增统一的合法日期/月校验。
- 统计 API 使用安全的日期区间计算。
- 记分 API 同时校验分类和行为项目均为启用状态。
- 顶部概览单独按当前月份查询或由月度统计结果计算，不受流水筛选影响。
- 导出前按当前统计筛选重新获取明细记录，确保 Excel、CSV、JSON 与页面统计一致。
- 分类统计同时返回正向贡献和负向贡献，图表不再使用绝对值掩盖方向。

### 阶段三：性能与交互

- 批量记分预先一次性读取已有重复键，避免逐学生查询。
- 流水增加分页参数和分页 UI，保留当前筛选条件。
- 展示批量记分成功数、跳过数和逐行原因。
- 修正历史按最新时间倒序显示。
- 增加规则排序操作或至少提供稳定的排序编辑入口。

### 阶段四：测试与发布质量

- API 回归：历史保护、停用分类、非法日期、统计范围、导出范围、快照展示。
- UI 回归：概览口径、筛选切换、导出按钮、空状态、分页、操作列布局。
- 浏览器级检查：桌面宽屏、窄窗口、窗口缩放、规则管理、日常流水、统计图表首次打开。
- 完整执行 `npm test`、`npm run build`、`git diff --check`。

## 4. 验收标准

- 删除学生或班级后，历史量化记录、快照和修正历史仍可追溯。
- 停用分类或行为项目后，前端不可选择，后端直接请求也必须拒绝。
- 顶部“本月”永远只统计当前自然月，不受流水筛选影响。
- 统计页三种导出格式的数据范围与当前月度/学期筛选一致。
- 非法月份和非法日期返回明确 400 错误。
- 加分和扣分在分类统计中方向明确，零数据状态可读。
- 批量记分不因重复查询导致明显性能退化，跳过原因可查看。
- 页面在宽屏和窄屏均无页面级横向空白或操作按钮截断。
- 所有自动化测试和生产构建通过。

## 5. 风险与兼容策略

- 不直接删除已有数据；数据库迁移必须幂等，并在迁移前创建恢复备份。
- 对已有量化记录保持原字段和原快照含义，不重算历史分值。
- 若历史表结构需要调整，优先增加字段或迁移约束，不覆盖原修正 JSON。
- 统计口径变更必须在版本更新说明和使用指南中记录。

## 6. 本轮实施状态（2026-08-16）

已完成：

- 量化历史保护：常规删除班级/学生时阻止已有量化历史被级联删除，并补充回归测试。
- 历史修正快照：修正记录展示分类、行为项目和分值的前后快照，修正历史按最新记录优先展示。
- 规则与日期校验：停用分类在后端拒绝新增记分；月份和统计日期范围使用严格校验及安全的日期计算。
- 统计与导出一致性：概览独立读取当前自然月；统计导出按当前月度/学期筛选重新获取明细；分类图表区分加分与扣分。
- 批量记分：去除逐学生重复查询，并在页面展示成功数、跳过数及逐行原因。

本轮暂缓、列入后续迭代：

- 流水记录分页与服务端分页 UI。
- 规则分类/行为项目排序编辑。
- 浏览器级多视口自动化回归；当前环境未提供可用的浏览器自动化执行器，需要人工验收窄屏、宽屏和缩放场景。
