# v0.6.0 教师主密码与模式安全体验 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将密码设置、修改、恢复与班级公开模式统一为清晰的“教师主密码 + 教师会话”安全体验，避免学生在共享电脑上看到成绩和隐私数据。

**Architecture:** 首次使用默认进入教师模式；只有教师主动开启班级公开模式后，软件才持久化公开状态。教师主密码只用于退出公开模式、进入教师工作台和修改安全设置；普通教师模块在同一会话内不重复验证，高度隐私模块支持可选二次验证。密码恢复使用一次性恢复密钥，不设置万能密码。

**Tech Stack:** Node.js、SQLite、Express、Vue 3、Element Plus、Tauri 2、Node 内置 `crypto.scrypt`、Node Test Runner。

**Spec:** `docs/2026-08-25-v0.6.0-隐私模式与工作台上锁-设计说明.md`

## Global Constraints

- 首次安装或未设置密码时默认进入教师模式，不强制弹出密码设置。
- 第一次开启班级公开模式前必须设置教师主密码。
- 班级公开模式启用后必须持久化，软件重启继续进入班级公开模式。
- 从班级公开模式进入教师工作台必须输入教师主密码。
- 密码、恢复密钥和验证结果不得以明文保存或出现在 URL、日志、备份导出内容中。
- 普通教师模块在教师会话内不重复验证；高度隐私模块支持额外验证开关。
- 密码修改必须验证当前密码；不强制定期改密；禁止固定万能密码。
- 教师会话闲置 30 分钟后自动回到班级公开模式。
- 所有新增行为先写失败测试，再实现最小代码并运行相关测试。

### Task 2: 设计后端密码设置、修改、恢复与模式切换接口

**Files:**
- Modify: `server/routes/access-control.js`
- Modify: `server/app.js` 的访问控制中间件注册
- Test: `tests/access-control-http.test.js`

**Interfaces:**
- `GET /api/access-control/state` 返回 `{ mode, hasPassword, teacherSessionExpiresAt, protectedModules }`，不返回密码摘要或恢复密钥。
- `POST /api/access-control/password` 接收 `{ password }`，首次设置密码并返回一次性 `{ recoveryKey }`。
- `POST /api/access-control/password/change` 接收 `{ currentPassword, nextPassword }`。
- `POST /api/access-control/password/reset` 接收 `{ recoveryKey, nextPassword }`。
- `POST /api/access-control/classroom-mode` 开启班级公开模式；已设置密码时不再要求输入密码，但必须由当前教师会话调用。
- `POST /api/access-control/teacher-session` 接收 `{ password }`，成功后建立教师会话。
- `DELETE /api/access-control/teacher-session` 清理教师会话并回到班级公开模式。

```js

  assert.match(await response.text(), /请先设置教师主密码/);
});

test('teacher session rejects wrong password and does not reveal password details', async () => {
  const response = await request('/api/access-control/teacher-session', {
    method: 'POST', body: { password: 'wrong-password' }
  });
  assert.equal(response.status, 401);
  assert.doesNotMatch(await response.text(), /scrypt|salt|hash/i);
});

test('recovery reset invalidates the old recovery key', async () => {
  const first = await request('/api/access-control/password', {
    method: 'POST', body: { password: '123456' }
  });
  const { recoveryKey } = await first.json();
  await request('/api/access-control/password/reset', {
    method: 'POST', body: { recoveryKey, nextPassword: '654321' }
  });
  const again = await request('/api/access-control/password/reset', {
    method: 'POST', body: { recoveryKey, nextPassword: '111111' }
  });
  assert.equal(again.status, 409);
});
```

**Interfaces:**

test('idle timeout returns the app to classroom mode', () => {
  const controller = createAccessController({ mode: 'classroom', teacherSession: true, now: 1000 });
  controller.touchTeacherSession(1000);
  controller.expireTeacherSession(1000 + 30 * 60 * 1000 + 1);
  assert.equal(controller.getState().teacherSession, false);
