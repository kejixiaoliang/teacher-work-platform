# v0.6.0 隐私模式与工作台上锁 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为教师工作台增加默认班级模式、教师密码切换、模块级临时解锁和后端接口保护。

**Architecture:** 在 Express 后端增加访问控制服务、内存授权 session 和 API middleware；在 Vue 前端增加访问控制 store、全局模式按钮、密码对话框与路由门控。密码摘要和模块策略进入 SQLite，运行时模式在进程内维护，应用启动强制回到班级模式。

**Tech Stack:** Vue 3、Vue Router、Element Plus、Express、better-sqlite3、Node.js `crypto.scrypt`、Node.js test runner。

**Spec:** `docs/2026-08-25-v0.6.0-隐私模式与工作台上锁-设计说明.md`

## Global Constraints

- 不保存教师密码明文，不把密码摘要或盐暴露给前端。
- 前端菜单和路由隐藏不能替代后端 API 授权检查。
- 应用重启后强制进入班级模式，不能记住上次教师模式。
- 默认开放概览、座位、考勤、表现量化；成绩、数据分析、学生管理、文档、家校沟通、请假、班级设置和备份受保护。
- 生产代码必须先有失败测试，再实现最小行为。
- 每项任务完成后运行对应测试；最终运行 `npm test` 和 `npm run build`。
