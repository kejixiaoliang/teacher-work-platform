# 教师工作台 v0.8.0 座位与值日修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复中间走道左右不均和值日星期/周次逻辑混用问题，并生成可测试的 v0.8.0 Windows 便携包。

**Architecture:** 座位页面使用纯边界计算决定走道前的列位置，当前、历史和打印共用 CSS 行为；值日后端为自动分组写入稳定的星期值，使用 `0` 表示固定模式下的未安排组，保留全空 `week_days` 的旧版周轮换兼容；前端按模式渲染当天摘要和星期表。构建阶段复用现有 Vite、Tauri 和便携打包脚本，不引入新依赖。

**Tech Stack:** Vue 3、Element Plus、原生 CSS、Express、SQLite、Node.js 内置测试运行器、Vite、Tauri v2。

**Spec:** `docs/superpowers/specs/2026-08-29-v0.8.0-座位值日修复设计.md`

### Task 1: 修正座位走道边界

**Files:**
- Create: `tests/seat-aisle-layout.test.js`
- Modify: `web/src/views/Seats.vue:372-378,761-768,827`

**Interfaces:**

- Produces: `isAisle(c)` 按走道前的边界返回位置；8 列中间走道为 4/4，双走道分区尽量均衡。

- [ ] **Step 1: Write the failing test**

在 `tests/seat-aisle-layout.test.js` 读取 `Seats.vue`，断言中间走道使用 `Math.floor(cols.value / 2) + 1` 的边界；断言双走道使用按三段累计边界而不是 `Math.ceil(cols / 3)` 的单点公式。

- [ ] **Step 2: Run test to verify it fails**

Run: `node --test tests/seat-aisle-layout.test.js`

Expected: FAIL，因为当前 8 列走道位于第 4 列前，导致 3/5。

- [ ] **Step 3: Write minimal implementation**

将 `Seats.vue` 的走道函数改为“指定走道前的座位列”：

```js
function isAisle(c) {
  const m = currentClass.value?.aisle_mode ?? 1;
  const total = cols.value;
  if (m === 0) return false;
  if (m === 1) return c === Math.floor(total / 2) + 1;
  const left = Math.ceil(total / 3);
  const middle = Math.floor((total - left) / 2);
  return c === left + 1 || c === left + middle + 1;
}
```

保留现有 `margin-left` 视觉间距，确保历史弹窗、打印和响应式样式继续对同一列生效。

- [ ] **Step 4: Run test to verify it passes**

Run: `node --test tests/seat-aisle-layout.test.js tests/seat-layout-ui.test.js tests/seat-movement.test.js`

Expected: PASS，走道边界和既有座位操作均通过。
