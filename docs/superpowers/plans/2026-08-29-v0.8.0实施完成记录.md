# v0.8.0 已知问题修复实施完成记录

## 本版本范围

本版本只修复既有反馈，不新增业务模块。重点完成：

- 学生字段采用预设目录，支持按班级显示/隐藏、改名、排序；数据库仍保留被隐藏字段及其数据。
- 学生模板与导出 Excel 随当前启用字段变化，并写入隐藏元数据工作表，便于后续版本识别。
- 备份升级为交换格式 v2，保存数据库 v8、能力声明和四类配置表；旧 v1 交换 JSON 与旧版 tables JSON 继续可恢复。
- 考试科目扩充预设，已有成绩的科目不能被删除；班级科目模板改为服务端持久化。
- 自动值日默认五组，默认对应周一至周五；值日表按当天星期优先显示。

## 兼容性约束

字段配置只引用内置稳定 key，不允许用户创建任意数据库列。新增字段数据存储在键值表中，升级版本不会因未知列导致结构错误。恢复旧备份时缺少的新配置表按空表处理；恢复新备份到旧版本应提示版本不受支持。

## 验证记录

- 数据库迁移、字段 API、备份归档、科目保护、值日分组均有 Node 测试。
- `npm run build` 已通过；构建产生的大 chunk 警告属于既有依赖体积提示。
- `docs/reusable-assets/` 保持原位置和内容，不参与归档删除。
