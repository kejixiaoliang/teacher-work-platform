# 教师工作台 · 下一阶段功能规划

## 一、规划目标

在现有班级、学生、座位、值日、班委、文档、成绩、考勤、请假和家校沟通能力之上，把系统从“信息管理工具”推进为“班主任日常工作台”。

核心目标：

1. 让班主任打开首页就知道今天要处理什么。
2. 让一个学生的长期情况可以在一个入口内完整查看。
3. 让高风险数据操作可预览、可恢复、可追溯。
4. 保持本地优先、单机可用和数据可迁移，不提前引入账号与云端复杂度。

## 二、实施顺序

### 阶段一：学生长期档案（当前执行）

- 建立学生统一时间线，合并成长记录、家校沟通、健康快照、成绩和考勤摘要。
- 学生详情中增加“需要关注”标记和跟进状态。
- 支持按时间、记录类型筛选。
- 保留现有成长档案和家校沟通的独立编辑入口，统一时间线只负责查看和跳转。

验收标准：打开学生详情即可按时间查看关键变化；任何一条时间线记录都能定位到原模块；原有编辑功能不受影响。

### 阶段二：班主任工作台首页

- 今日待办、今日考勤、今日请假、今日值日、近期考试集中展示。
- 预警支持查看学生和标记已处理。
- 增加班级临时事项和到期提醒。

### 阶段三：报表与通知

- 成绩单、考勤月报、座位表和值日表统一导出/打印。
- 增加可复用的班级通知模板。
- 支持批量生成学生或家长通知文本。

### 阶段四：数据安全与可追溯

- 导入前预览、冲突提示和失败回滚。
- 自动备份与备份版本列表。
- 删除、恢复、导入、备份恢复操作日志。
- 恢复前自动创建快照。

### 阶段五：通用化能力

- 自定义学生字段和标签。
- 自定义班委角色、请假类型、沟通方式和成绩科目。
- 字段显示/隐藏与排序配置。

### 阶段六：班级日历

- 汇总值日、考试、请假、家校沟通和班级临时事项。
- 支持月视图、周视图和到期提醒。

## 三、当前执行任务

本分支先完成阶段一的基础数据层：新增学生统一时间线只读接口，统一返回成长记录、家校沟通和健康快照，并保留来源类型与来源 ID，供学生详情页后续展示。

暂不在本批次引入新的编辑模型、账号系统或云端同步。
