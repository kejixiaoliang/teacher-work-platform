# 教师工作台 · 亲测反馈与优化方案

> 来源：实际使用测试后的完整反馈（2026-07）
> 状态：待执行 → 逐步落地
> 关联分支：`style/content-lab`

---

## 一、概览首页：太「空」，希望更直观

**现状**
- 首页只有 hero + 3 张功能卡（今日值日 / 座位缩略图 / 最近文档）+ 1 张数据管理卡
- 信息密度低，打开后看不到班级「全景」

**目标**
- 增加可直接观看、无需点进去的模块，例如：
  1. **班级概况条**：人数 / 男生 / 女生 / 近视人数 / 住宿人数 / 平均身高（一行统计胶囊）
  2. **班委 & 课代表一览**（只读卡片）：班长、学委、各科课代表是谁，一眼看清
  3. **今日概览**：今日值日组 + 今日考勤简况
  4. **近期数据提醒**：成绩最近一次考试概况、未入座人数提醒
- 原则：只看不编辑，能知道「谁是谁、班里有啥」

## 二、学生管理（问题最多）

### 2.1 表格没占满，右侧大片空白
**现状**：表格列宽固定（各列 width 固定），班级人数少时表格右侧空出一大块
**方案**：
- 关键列（姓名/学号）用 `min-width` + 弹性分配，让表格铺满容器
- 增加信息列：家长电话 / 座位号 / 职务特长 / 备注，让列数更充实
- 或右侧补一块「班级统计小卡」（与表格并排）

### 2.2 编辑/删除按钮：上下排列 + 阴影错乱
**现状**：`el-button link` 两个按钮竖排（link 按钮本身是 inline），且贴纸阴影导致视觉叠加
**方案**：改为横向排列，用带间距的按钮组（`编辑` + `删除` 并排），去掉叠加阴影

### 2.3 点击行 vs 点击「编辑」内容不一致
**现状**：
- 点行 → 打开右侧抽屉（基本信息 / 身高视力历史 / 成长档案 / 家校沟通 4 个 tab）
- 点「编辑」→ 打开编辑弹窗（改资料）
**反馈**：点行时希望能直观看到：基本信息、身高、视力、历史成长档案、家校沟通
**方案**：
- 行点击 → 详情抽屉（保留 4 tab，但优化 tab 内容与排版）
- 抽屉内「基本信息」增加身高/视力醒目展示
- 编辑按钮 → 编辑弹窗，两者职责分明，并在 UI 上明确提示

### 2.4 成长档案 & 家校沟通：可继续添加记录
**现状**：抽屉内已有「添加记录」「添加沟通」按钮 + 弹窗
**反馈**：希望进一步方便添加（入口太深）
**方案**：
- 抽屉内列表项增加「快速再添加」入口
- 记录项支持**编辑/删除**（目前只有删除）
- 弹窗默认带出当前日期，减少填写成本

### 2.5 交互：入口隐藏太深
**方案**：
- 表格行增加视觉提示（hover 高亮 + 提示「点击查看详情」）
- 行内加「详情」按钮，和编辑/删除并排，入口更明显

### 2.6 UI：删除按钮、小分类按钮与背景融为一体
**现状**：link 类型小按钮颜色浅、贴纸阴影样式下不明显
**方案**：
- 行内操作按钮改为**实心小胶囊**（编辑=白底墨边、详情=薄荷、删除=番茄），对比明显
- 表格顶部筛选区（性别/状态/近视/住宿）按钮改为清晰可点的样式

### 2.7 排版优化
- 详情抽屉宽度加大，描述项分组（「基础」「健康」「联系」「其他」）
- 表格空数据时显示更友好的引导

## 三、座位管理

### 3.1 增加「不近视」标签
**现状**：座位卡只显示「近视」（chip-warn），正常视力无标记，座位显得乱
**方案**：视力正常者显示薄荷色「不近视」chip，近视者保持芥末色「近视」chip

### 3.2 蓝色底 / 粉色底含义不明
**现状**：`.seat.boy` 薄荷绿底（男）、`.seat.girl` 淡粉底（女），但页面无图例
**方案**：
- 座位区上方加**图例**：🟢 男生 / 🌸 女生 / 🔒 锁定 / 空座（虚线），一目了然

### 3.3 有人座位 vs 空座高度不一致
**现状**：有人座位有 chip（身高/视力/近视）变高，空座只有一行「空」变矮
**方案**：
- 空座也保持 `min-height`（与有座等高），内容用占位符对齐

### 3.4 进一步优化
- 座位卡信息精简对齐（身高/视力/近视/不近视统一排布）
- 选中/拖拽状态更清晰

## 四、成绩录入：支持 Excel 导入

**现状**：仅支持手动逐格录入
**反馈**：很多学校系统可导出 Excel 成绩，希望直接导入
**方案**：
- 成绩录入 tab 增加「导入成绩 Excel」按钮
- 支持模板：列 = 学号/姓名 + 各科目，或按现有考试科目匹配表头
- 导入前预览（学号匹配学生 → 科目匹配 → 分值校验），确认后写入
- 参考学生管理已有的 exceljs 导入实现

---

## 五、考勤月度统计：表格自适应

**现状**：月度统计表格列宽固定，容器拉宽后右侧空一大块白
**方案**：
- 去掉固定列宽（或改 `min-width`），让列弹性铺满
- 统计列（出勤/迟到/请假/缺勤）居中对齐

---

## 六、文档管理：标签预设模板

**现状**：仅支持按文件类型分类 + 自由输入标签
**反馈**：希望提供标签**预设模板**供选择
**方案**：
- 侧边栏「标签」区提供常用预设（如：教案、试卷、课件、通知、家长信、表格模板、其他）
- 预设标签可一键点击筛选，也保留自由输入

---

## 七、值日管理：「加人」「删组」按钮白边问题

**现状**：`el-button link` 小按钮在卡片底色上显示为白边/与底色融合，显脏
**方案**：
- 组卡内的「加人」「删组」改为清晰小按钮（胶囊/实心）
- 与 2.6 的按钮风格统一

---

## 八、班委学委：支持「编辑」

**现状**：只有「解除」，改人/改备注只能先解除再重选
**方案**：
- 操作列增加「编辑」，弹窗预填当前职务/学生/备注，可改人、改备注

---

## 九、菜单栏：新增「课代表选择」

**现状**：班委学委页只含固定班委职务
**方案**：
- 菜单新增「课代表」入口（或并入班委页作为 tab）
- 每个科目选一个课代表（语文/数学/英语/物理/化学/生物/政治/历史/地理…），与班委数据同表（role 前缀区分）或独立表
- 课代表信息可在首页展示

---

## 十、首页：班委/课代表/预设信息大屏展示

**现状**：首页只有功能入口
**目标**：完成预设后，首页像「班级信息大屏」，只看不编辑就能知道：
- 班委是谁、各科课代表是谁
- 今日值日、今日考勤
- 班级人数/近视/住宿等概况
- 让首页成为班主任的「一眼看班」面板
