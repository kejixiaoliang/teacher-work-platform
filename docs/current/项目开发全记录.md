## 一、项目是什么

**教师工作台（班主任版）**——面向班主任的单机 Web 应用：管学生、排座位、记成绩、盯考勤、收文档、轮值日、管班委课代表、记请假与家校沟通。

**它不是普通网页，也不是 localStorage 伪单机**，而是一套完整的「前端 + 后端 + SQLite 数据库」三层应用：

```
浏览器 (Vue3)  →  fetch  →  Express API（参数化 SQL + 校验 + 事务）  →  SQLite
```

- 数据存本地 `data/teacher.db`（13 张业务表、外键级联、UNIQUE 约束、索引）
- 上传文件存 `data/files/`
- **备份 = 复制整个 `data/` 文件夹**
- 双击 `启动.bat` 即用，无需联网、无需账号

**踩坑记录**：
- **exams 唯一索引崩溃（重要）**：给 exams 加 `UNIQUE(class_id,name)` 时，库里已有重复「示例·期中考试」→ `CREATE UNIQUE INDEX` 失败 → **server 启动即崩** → 用户一直连旧进程 → 新接口 404「服务器异常」。解法：建索引前先 `DELETE` 清理同班同名重复（保留每组最新一条）
- **ExcelJS `row.cells` 不存在**：学生导入/成绩导入原本就用 `row.cells[0]`，ExcelJS 的 Row 只有 `getCell()`——**两个导入功能本来就是坏的**。改用 `row.getCell(n)`
- **切班竞态**：快速切班时旧班级响应覆盖新数据，Scores 录入表可能显示错班学生

### 阶段 7：学生管理空白 Bug（`abfacaa`）—— 最诡异的一次

**现象**：学生管理页面一片空白，学生数据全不显示。

**排查过程**（多轮）：
1. 先怀疑端口/缓存：停旧进程、重启 server、强刷——无效
2. 用 PowerShell 读文件显示「乱码」→ 一度误判文件损坏 → 实际是 PowerShell 控制台用 GBK 解码 UTF-8 的**显示问题**，文件完好
3. 用 Vite SSR 加载组件 → 终于抓到真相：**`computed is not defined`**
4. **根因**：加前端分页时用了 `computed(() => ...)` 定义 pagedList，但 `import { ref, reactive, watch, ... } from 'vue'` 里**漏了 computed**
   - vite 构建不报错（未 import 标识符当作普通变量，不校验）
   - 浏览器运行 setup 到 `computed(...)` 抛 ReferenceError → 整个组件渲染中断 → 空白

**解法**：补上 `computed` import。

**教训**：**构建通过 ≠ 运行时正确**。未 import 的标识符构建期不报错。此后用 SSR 渲染全页面 + import 完整性扫描脚本兜底验证（13 页全过 + 图标 import 全过）。

### 阶段 9：启动脚本修复（`6db5d9d` + `f081e1a`）

**用户反馈**：点 `启动.bat` 有时没反应，浏览器打不开；且启动后不能关黑窗口。

**问题根因**：
1. **BAT 中文乱码（致命）**：原 BAT 是 UTF-8 无 BOM，cmd 解析时中文行被拆成乱码命令（`'le' is not recognized`）→ 脚本逻辑错乱 → 服务根本没启动
2. **无端口检测**：端口被占（旧窗口没关/残留 node/重复点击）→ EADDRINUSE 崩溃闪退
3. **黑窗口一关服务就停**

**解法**：
- BAT 改为 **UTF-8 with BOM**（cmd 正确解析中文）
- 启动前 PowerShell 检测 3210：端口空闲 → 正常启动；health 200 → 提示「已在运行」直接开浏览器；health 失败 → 提示「端口被占用」+ 处理办法
- **服务最小化后台运行**：Start-Process 启动 node（最小化独立窗口），启动器窗口显示说明后自动关闭——黑窗口可安全关，停止服务从任务栏关「node」窗口
- server 端口占用时友好提示 + 退出码 1，不抛堆栈

**踩坑记录**：
- PowerShell here-string 写 GBK 文件时字符转换出错（`教师工作台` 变乱码）→ 改 Node 脚本生成 UTF-8 BOM
- cmd 的 `start "title" /min cmd /c "npm start"` 嵌套引号 + 重定向问题 → 改用 PowerShell `Start-Process node`，绕开嵌套 cmd
- 无头测试环境对 cmd stdin 重定向敏感（`Input redirection is not supported`），与真实双击行为不同，需用 Start-Process 模拟双击验证

## 四、关键设计决策回顾

| 决策 | 理由 |
|---|---|
| 单机 Web 应用而非纯桌面 | 双击即用、浏览器操作、无安装门槛，又保留真实后端 |
| SQLite 而非 localStorage | 结构化、事务、查询索引、数据独立于浏览器 |
| 小亮实验室风格 | 用户明确要求的品牌视觉，暖纸手绘降低「管理后台冷感」 |
| 4px 粗线 + 实色错位投影 | 手绘贴纸感的核心，但只用于一级容器避免视觉噪音 |
| 路由懒加载 + 按需引入 | 首屏 3.38MB → 1.04MB，12 页独立 chunk |
| useSeqLoad 每数据域独立实例 | 避免并发请求相互作废（踩过坑） |
| 构建生成 .gz + 服务端 gzip | 传输体积减 ~70%（200MB 大文件场景无感） |
| BAT 端口检测三态分流 | 重复点击不再崩溃，残留进程可诊断 |
| 服务最小化后台运行 | 黑窗口不再碍事，停止服务从任务栏操作 |

## 五、踩坑清单（速查）

1. **exams 唯一索引与既有重复数据冲突 → server 启动即崩**（先清理再建索引）
2. **db.js 索引块在建表前 → 全新库 no such table**（移到建表后）
3. **ExcelJS `row.cells` 不存在**（用 getCell）
4. **useSeqLoad 单实例共享计数器 → 并发 load 相互作废**（每数据域独立实例）
5. **computed 未 import → 构建通过但运行 ReferenceError 整页空白**（SSR 验证兜底）
6. **BAT UTF-8 无 BOM → cmd 中文乱码整行当命令**（UTF-8 with BOM）
7. **BAT 嵌套 cmd start 引号/重定向问题**（改用 PowerShell Start-Process）
8. **PowerShell here-string 写 GBK 字符转换错乱**（用 Node 脚本生成文件）
9. **番茄红白字对比度不足**（加深 #d64541）
10. **info 按钮灰蓝冷色与风格冲突**（改暖纸色）
11. **dblclick 与按钮 click 冒泡冲突**（单击预览 + 操作区统一 stop）
12. **切班未保存数据丢失**（四重拦截：切班/切日期/路由离开/刷新）
13. **多 server 进程抢占端口 → 旧进程服务旧产物**（统一端口，强刷缓存）
14. **无头环境 cmd stdin 重定向敏感**（测试方法要模拟真实双击）
