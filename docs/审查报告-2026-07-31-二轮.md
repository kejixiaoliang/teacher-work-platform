## 四、一致化加固（loading/并发/校验）

### 4.1 loading 提前关闭（8 处）

`Overview / Duties / Leaders / SubjectLeaders / Documents / Analytics / Leaves / Contacts` 的 `finally { loading=false }` 无条件关闭——快速切班时旧请求的 finally 会关掉新请求的 loading。统一改为：

```js
finally { if (!isStale(mySeq)) loading.value = false; }
```

（Attendance 原实现即正确模式，作为参照）

### 4.2 串行双请求 → 并行独立落值（5 处）

`Leaves(list+today) / Contacts(list+stats) / Duties / Leaders / SubjectLeaders(duties+students)` 由「串行 await、一败全败」改为：

```js
const [aRes, bRes] = await Promise.allSettled([...]);
if (aRes.status === 'fulfilled') ... else ElMessage.error(...)
```

### 4.3 api.js 可靠性（P2 但影响全站）

- **不检查 HTTP `r.ok`**：后端 4xx/5xx 时 `r.json()` 解析失败统一报「服务器响应异常」，误导排查
- 无超时：慢请求永久 pending 卡死 loading
- `documents.upload` 同样未检查状态

修复：先 `if (!r.ok)` 按状态抛错 → 再解析 JSON；15s `AbortController` 超时（超时报「请求超时」）；upload 补状态检查。

### 4.4 后端输入校验（review 建议统一）

| 项 | 修复 |
|---|---|
| 删除类端点非法 id | classes/documents/duties/leaves/scores/seats/students/records 的 `DELETE` 补 `Number.isInteger && >=1` 校验，非法返回 400（原静默 `ok:true`） |
| 软删学生写考勤/成绩 | `attendance.js`/`scores.js` 的 validIds 排除 `deleted_at IS NULL`，回收站学生不可写入 |
| attendance month | 补 `YYYY-MM` 正则校验 |
| seats shift dr/dc | 数值化取整（原字符串参与模运算） |
| 外键子表索引 | `seats/exam_scores/duties/attendance` 的 `student_id` 补索引（级联删除免全表扫） |
| `/api` 未知路由 | 统一 JSON 404（原 Express 默认 HTML，泄露版本号） |
| 静态资源缓存 | gz 产物加 `Cache-Control: public, max-age=31536000, immutable`，index.html `no-cache` |
