## 一、版本背景

本版本主要根据两位老师的实际使用反馈，围绕“班级电脑供学生或班干部使用时，不能看到教师隐私数据”这一核心问题进行设计和开发。

反馈中涉及的隐私内容包括：

- 成绩和成绩分布
- 学生档案与学生详情
- 家校沟通记录
- 学生谈心、事件留痕等跟进信息
- 心理测评等高度敏感内容
- 班级管理和系统配置

同时，老师希望软件仍然可以保留班级签到、加分、座位、值日等适合学生或班干部操作的功能。因此，本版本没有把软件简单改成“启动即登录”，而是设计为教师模式与班级公开模式之间的安全切换。

## 二、核心产品决策

### 1. 默认进入教师模式

首次安装或历史数据没有模式配置时，软件默认进入教师模式，方便教师第一次使用和配置班级。

### 2. 教师主动开启班级公开模式

教师在顶部工作台入口点击“开启班级公开模式”后，软件进入适合班级电脑使用的公开状态。

开启公开模式前，如果尚未设置教师主密码，系统会先引导教师完成密码设置。

### 3. 班级公开模式持久化

一旦教师开启班级公开模式，软件会保存该模式。下次重启时继续进入班级公开模式，避免学校电脑重启后直接暴露教师数据。

### 4. 教师会话不持久化

教师输入密码进入教师工作台后，只建立当前进程内的教师会话。软件重启、自动回锁或主动退出教师工作台后，教师会话失效。

### 5. 一个教师主密码

系统使用一个教师主密码统一保护：

- 从班级公开模式进入教师工作台
- 修改教师安全设置
- 查看受保护模块
- 重置访问密码

普通模块不重复输入密码；高度隐私模块后续可以继续扩展二次验证策略。

## 三、功能实现内容

### 3.1 教师主密码

实现内容：

- 支持首次设置教师主密码
- 支持旧密码验证
- 支持修改教师主密码
- 新密码和确认密码一致性校验
- 密码长度限制为 6 至 64 位
- 使用 Node.js `crypto.scrypt` 生成密码摘要
- 每个密码使用随机盐
- 使用 `timingSafeEqual` 进行摘要比较
- 不向前端返回密码摘要、盐或算法细节
- 不在日志、URL 或文件名中记录明文密码

修改密码后：

- 当前密码立即失效
- 当前教师会话回到班级公开模式
- 重新进入教师工作台必须使用新密码
- 同时生成新的密码恢复密钥

### 3.2 一次性恢复密钥

为避免教师忘记密码后无法使用软件，本版本增加恢复密钥机制。

首次设置或修改密码时生成高熵随机恢复密钥：

- 恢复密钥为 32 位十六进制字符串
- 数据库只保存 SHA-256 摘要
- 前端只在生成成功后显示一次
- 前端会尝试自动复制到剪贴板
- 恢复密钥不能直接查看业务数据
- 恢复成功后旧恢复密钥立即失效
- 重置成功后生成新的恢复密钥

恢复流程：

1. 教师进入“班级设置 → 隐私与访问控制”
2. 点击“忘记密码”
3. 输入恢复密钥
4. 输入新密码和确认密码
5. 重置教师主密码
6. 保存系统生成的新恢复密钥

重置密码不会删除班级、学生、成绩或其他业务数据。

### 3.3 教师模式与班级公开模式

教师模式：

- 可以查看全部业务模块
- 可以修改隐私配置
- 可以修改教师主密码
- 可以进入成绩、学生档案、家校沟通等隐私模块

班级公开模式：

- 只开放配置为 `open` 的模块
- 隐藏或保护成绩、分析、学生隐私等内容
- 学生或班干部可以使用已开放的班级管理功能
- 顶部只显示“教师入口”
- 输入正确教师主密码后才能回到教师工作台

顶部状态入口统一显示当前模式：

- `教师模式`
- `班级公开模式`

模式切换入口与密码设置入口分离：

- 顶部入口负责日常模式切换
- 班级设置中的“安全与隐私”负责密码修改、恢复密码和公开模块配置

### 3.4 模块访问策略

当前模块策略分为：

- `open`：班级公开模式可以使用
- `protected`：只有教师模式或临时授权可以使用

默认保护模块包括：

- 数据分析
- 成绩管理
- 学生管理详情
- 文档管理
- 请假管理
- 家校沟通
- 班级设置
- 备份恢复

默认开放模块包括：

- 概览首页
- 座位管理
- 考勤管理
- 表现量化
- 部分班级事务模块

前端路由拦截只负责用户体验，后端接口权限检查才是最终安全边界。

### 3.5 自动回锁

教师模式闲置 30 分钟后自动回到班级公开模式：

- 清理教师会话
- 清理临时模块授权
- 后端接口重新执行班级公开权限
- 前端刷新访问状态

教师也可以主动退出教师工作台，立即回到班级公开模式。

## 四、后端实现

### 4.1 访问控制核心模块

主要文件：

- `server/access-control.js`

核心职责：

- 密码摘要生成与验证
- 恢复密钥生成与验证
- 教师模式与班级公开模式管理
- 模块策略管理
- 临时模块授权
- 教师会话和自动回锁
- 安全状态输出

### 4.2 访问控制路由

主要文件：

- `server/routes/access-control.js`

当前接口包括：

| 接口 | 作用 |
|---|---|
| `GET /api/access/status` | 获取当前访问状态 |
| `POST /api/access/password` | 首次设置教师主密码 |
| `POST /api/access/password/change` | 修改教师主密码 |
| `POST /api/access/password/reset` | 使用恢复密钥重置密码 |
| `POST /api/access/mode` | 兼容原有模式切换接口 |
| `POST /api/access/classroom-mode` | 开启班级公开模式 |
| `POST /api/access/teacher-session` | 输入密码进入教师工作台 |
| `DELETE /api/access/teacher-session` | 退出教师工作台 |
| `POST /api/access/unlock-module` | 临时解锁单个模块 |
| `PUT /api/access/policies` | 修改公开模块策略 |
| `POST /api/access/lock` | 立即回锁 |

密码错误统一返回用户可理解的错误信息，不暴露内部摘要、盐或验证细节。

### 4.3 后端统一权限中间件

主要文件：

- `server/app.js`
- `server/runtime.js`

后端在所有业务 API 前检查：

1. 当前访问模式
2. 当前模块策略
3. 当前临时授权是否过期
4. 当前教师会话是否仍然有效

班级公开模式访问受保护 API 时返回：

```text
HTTP 403
code: MODULE_LOCKED
```

运行时从 `app_settings` 读取并保存：

- `access.password`
- `access.policies`
- `access.mode`
- `access.recovery-key-hash`
- `access.recovery-key-used-at`

## 五、前端实现

### 5.1 访问状态管理

主要文件：

- `web/src/accessControl.js`

提供：

- 当前模式状态
- 当前密码是否已设置
- 当前公开模块策略
- 教师模式进入和退出
- 班级公开模式开启
- 密码设置与恢复
- 自动回锁状态刷新

### 5.2 顶部模式入口

主要文件：

- `web/src/App.vue`

主要交互：

- 顶部显示当前模式
- 教师模式显示“开启班级公开模式”
- 班级公开模式显示“教师入口”
- 首次设置密码时要求输入两次密码
- 设置成功后展示恢复密钥
- 进入教师工作台时只要求输入教师主密码

### 5.3 班级设置安全面板

主要文件：

- `web/src/views/Classes.vue`

提供：

- 当前访问模式展示
- 公开模块配置
- 修改教师主密码
- 新密码确认
- 忘记密码入口
- 恢复密钥重置密码
- 自动回锁说明

### 5.4 受保护页面

主要文件：

- `web/src/views/AccessLocked.vue`
- `web/src/router.js`

班级公开模式访问受保护路由时，前端跳转到“此模块已保护”页面，并引导教师从顶部“教师入口”验证主密码。

## 六、数据库与版本变化

本版本沿用 v6 的 `app_settings` 表保存访问控制配置，数据库用户版本保持为 v6。

历史数据库兼容策略：

- 没有访问模式配置的旧数据库默认进入教师模式
- 没有教师密码时可以继续使用教师模式
- 首次开启班级公开模式前必须设置密码
- 不删除已有班级、学生、成绩和业务数据
