# v0.6.0 隐私模式与工作台上锁发布检查清单

> 归档说明：历史版本资料，仅用于追溯当时的实现与发布过程。

## 功能验收

- [x] 首次启动默认进入教师模式；首次开启班级公开模式前设置教师主密码，密码摘要和盐不进入前端存储。
- [x] 正确密码可以从班级公开模式进入教师工作台；开启班级公开模式不重复要求密码。
- [x] 错误密码不能改变当前模式。
- [x] 应用重启后继续使用已持久化的班级公开模式，教师会话不会恢复。
- [x] 修改教师主密码要求旧密码、新密码和确认密码。
- [x] 恢复密钥可单次重置密码，旧恢复密钥再次使用会被拒绝。
- [x] 成绩、数据分析、学生详情、文档、请假、家校沟通和班级设置在班级模式下受保护。
- [x] 受保护 API 返回 `403 MODULE_LOCKED`。
- [x] 班级模式下基础学生接口仅返回课堂所需字段。
- [x] 受保护路由直接访问时进入“此模块已保护”页面。
- [ ] Windows 便携包人工检查首次设置密码、保存恢复密钥、切换模式、权限配置和重启回到班级公开模式。
