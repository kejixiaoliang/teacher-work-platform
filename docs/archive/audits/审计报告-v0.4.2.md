## 一、目标

本版本只处理两个高价值优化：

1. 将数据库、上传附件和清单打包为可迁移 ZIP，并支持安全恢复。
2. 将文档文件 URL 的长期 API token 改为 30 秒一次性授权。

## 三、安全边界

- ZIP 仅允许 `backup.json` 和 `files/<basename>` 条目，拒绝目录穿越、绝对路径、重复条目和超限归档。
- 恢复失败时清理临时文件，并回滚已替换的附件目录；数据库继续保留恢复前快照。
- API token 仅用于申请文件 token；文件流 token 不可跨文档、不可重复使用、不可访问普通 API。
- 文件响应继续使用 `nosniff`、`no-referrer` 和 `no-store`。
