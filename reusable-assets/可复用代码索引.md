# 可复用代码索引

这些代码没有复制到归档目录，避免产生两份会逐渐漂移的实现；重新实现时按下表从原分支提取，并先补充针对新运行时的测试。

| 源文件 | 可复用内容 | 使用方式 |
| --- | --- | --- |
| `shared/contracts/exchange.js` | 交换包字段、版本和集合白名单 | 作为跨端 JSON 契约的唯一来源 |
| `shared/contracts/cloud-record.js` | 云记录元数据、稳定 UUID、导入批次 | 在服务端写入前统一规范化 |
| `shared/exchange/normalize-legacy.js` | legacy tables v1/v2 迁移 | 作为导入兼容层，不放进页面组件 |
| `shared/contracts/sync.js` | 变更队列、游标、冲突检测概念 | 只作为真正同步实现的起点，不能宣称已完成 |
| `server/utils/backup-format.js` | 桌面端备份完整性和归档规则 | 与小程序交换格式保持兼容 |
| `cloudfunctions/import-data` | 预检、预览、提交、重复导入保护 | 保留预检与 commit 分离 |
| `cloudfunctions/backup-data` | 按教师/数据集/班级导出完整数据 | 重新验证集合清单和脱敏规则 |
| `cloudfunctions/excel-exchange` | 学生/成绩 Excel 解析与生成 | 保留字段映射和公式注入防护 |
| `cloudfunctions/student-data` | 学生列表、写入、软删除边界 | 重新核对产品需要的完整操作闭环 |
| `cloudfunctions/business-data` | 座位、值日、班委、联系、分析等作用域校验 | 按模块拆分测试后再接入客户端 |
| `miniprogram/services/student-import-service.js` | 本地解析、预检、失败报告 | 迁移算法，不直接复制页面耦合 |
| `miniprogram/services/score-file-service.js` | 成绩交换解析、导出和安全处理 | 迁移算法并重新做真机文件测试 |
| `miniprogram/services/seat-layout-service.js` | 座位网格和排座算法 | 先与桌面端结果做固定样例对照 |

当前 `miniprogram/pages/` 目录只适合作为业务字段和页面名称参考，不建议作为新小程序的基础模板。
