# 可复用资产归档

本目录从 `codex/v0.8.0-cloudbase-foundation` 分支中提取，供重新实现微信小程序或其他客户端时参考。原始文件仍保留在原目录；本目录中的副本是归档快照，不自动代表线上当前状态。

## 使用结论

| 类别 | 建议 | 内容 |
| --- | --- | --- |
| 数据契约与安全边界 | 可直接复用，先做回归测试 | JSON 交换格式、稳定 UUID、所有者隔离、数据集/班级作用域、软删除、修订号 |
| CloudBase 数据设计 | 可复用设计，部署前重新核对 | 集合、索引、权限、云函数调用约定 |
| 导入/导出算法 | 可迁移，需适配新客户端 | JSON、Excel、公式注入防护、重复导入保护、错误报告 |
| UI 规划与信息架构 | 作为参考，不要整套复制 | 三栏入口、移动端触达尺寸、状态/空页面原则 |
| 当前小程序页面 | 不建议直接继承 | 未完成完整客户端等价，也未完成真实微信端验收；应重新实现页面和运行时接入 |
| 同步实现 | 仅保留概念模型 | 当前 `sync-data` 只是状态检查，不是真正双向同步 |

## 目录

- `docs/`：数据契约、架构、迁移、功能覆盖和 UI 原则。
- `docs/2026-08-28-v0.7.0-客户端数据兼容与版本升级规范.md`：只针对桌面客户端的长期兼容承诺和发布门槛。
- `docs/2026-08-28-v0.8.0-客户端迁移小程序全过程复盘与后续方法论.md`：全过程失败复盘、证据分级和以后执行迁移项目的流程。
- `cloudbase/`：集合、权限、索引、函数和部署资料；部署状态使用前必须重新核验。
- `history/`：本阶段执行总结，仅作历史背景，不作为现状依据。
- `可复用代码索引.md`：源代码位置、迁移方式和风险说明。
- `2026-08-28-v0.8.0-小程序重做经验教训与取舍建议.md`：本次项目的复盘结论。

## 重要边界

本目录不包含被 `.gitignore` 忽略的 `miniprogram/config/env.js`，也不保存任何密钥。重新建项目时必须单独配置 CloudBase 环境，并使用脱敏测试数据和独立测试数据集进行真实验收。
